# Access Modifiers in TypeScript OOP

Access modifiers control the visibility and encapsulation of class properties and methods. TypeScript provides four main keywords:

- **`public`**: Accessible from anywhere—inside the class, child classes, and external instances.
- **`private`**: Restricted strictly to the class where they are declared; hidden from child classes and outside code.
- **`protected`**: Accessible inside the declaring class and its child classes, but hidden from external instances.
- **`readonly`**: Prevents a property from being reassigned after its initial value is set in the constructor.
