# TypeScript Assignment: Problem Solving & OOP

## Overview
This repository contains my solutions to the TypeScript assignment covering Modules 1, 2, and 3. The assignment has eight problem-solving tasks and two blog posts. All solutions are in a single file, `solutions.ts`.

## Topics Covered
- Basic types, optional and default parameters
- Union types and type narrowing
- Readonly tuples
- Interfaces and generics (including `keyof`)
- Promises and `async` handling
- Classes, inheritance, and access modifiers

## Files
- `solutions.ts`: solutions to all eight problems
- `README.md`: this file
- Two blog posts (linked below)
